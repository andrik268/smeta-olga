# Ольга Потолицына | Инженер-сметчик

Лендинг для инженера-сметчика из брифа клиента. Светлая бежево-оливковая палитра, спокойная B2B-подача, акцент на доверии, проверяемом опыте и экспресс-оценке сметы.

## Запуск

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
```

Фото для лендинга созданы специально под визуальное направление проекта и лежат в `public/images/`.
